# Data card

Intended source: official Rebrickable set/theme CSV downloads supplied locally.
The build agent could not verify current source terms or fetch the source pages
(HTTP 402); the operator supplied the raw files, and source terms remain the operator's
responsibility. Current local catalog: 28,587 source rows reduced to 500 selected sets,
dataset version `78b8926d0b520375`, with 486 verified local images. Canonical schema:
set_id, name, year, theme_id, theme, num_parts, optional image_url, source attribution.
Prices, age ratings and popularity are unavailable and are not inferred.
Raw files, cached images and feedback remain excluded from version control.
Feedback contains local aliases, set IDs, actions and timestamps; do not publish it.
Synthetic unit fixtures test invariants and are not evaluation or product data.
